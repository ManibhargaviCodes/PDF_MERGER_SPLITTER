#  PDF Merger & Splitter

A simple and efficient Python application to merge multiple PDF files into one document and split a PDF into individual pages using the **pypdf** library.

##  Features

-  Merge multiple PDF files into a single PDF
-  Split a PDF into separate pages
-  Easy menu-driven command-line interface
-  Fast and lightweight
-  Automatically saves output files

##  Project Structure

```
PDF_MERGER_SPLITTER/
├── input_pdfs/
├── output/
├── main.py
├── README.md
└── requirements.txt
```

##  Technologies Used

- Python 3
- pypdf

##  Installation

Clone the repository:

```bash
git clone https://github.com/ManibhargaviCodes/PDF_MERGER_SPLITTER.git
```

Install the required library:

```bash
pip install -r requirements.txt
```

##  Run the Project

```bash
python main.py
```

##  How It Works

1. Place your PDF files inside the `input_pdfs` folder.
2. Run the application.
3. Choose:
   - **1** → Merge PDFs
   - **2** → Split a PDF
4. Generated files are saved in the `output` folder.

##  Example

**Input**
```
input_pdfs/
├── sample1.pdf
└── sample2.pdf
```

**Output**
