# PDF Merger & Splitter

## Description
A Python project to merge multiple PDF files into one PDF and split a PDF into individual pages.

## Features
- Merge multiple PDFs
- Split PDF into pages
- Simple menu-driven interface

## Technologies Used
- Python
- pypdf

## How to Run

1. Install the library:
```bash
pip install -r requirements.txt
```

2. Run the program:
```bash
python main.py
```
