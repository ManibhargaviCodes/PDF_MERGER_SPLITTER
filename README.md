# PDF Merger & Splitter

## Description
This is a Python project that can merge multiple PDF files into a single PDF and split a PDF into separate pages.

## Features
- Merge multiple PDF files
- Split PDF into individual pages
- Easy command-line interface
- Fast and simple to use

## Technologies Used
- Python
- pypdf

## Project Structure

```
PDF_MERGER_SPLITTER/
│── main.py
│── input_pdfs/
│── output/
│── README.md
│── requirements.txt
```

## Installation

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python main.py
```
